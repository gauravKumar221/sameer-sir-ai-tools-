# AutoGreen AI — AI is the new green. 🌿

A global AI ecosystem helping people and businesses discover, use, automate, and build with artificial intelligence. Different Businesses. One Green.

## 🚀 Key Features

- **AutoGreen AI Ecosystem Homepage**:
  - Hero with animated constellation particle canvas & emerald theme.
  - 6 Core Pillars Bento Grid (Discover, Kits, Automate, Agents, Voice, Studio).
  - AI Marketer Kit Showcase (Starter, Community, Expert) with instant DRM checkout.
  - Interactive AI Agents Directory (Research, Marketing, Support, Reporting, Lead Qualification).
  - Automated Workflows & Voice AI latency showcase.
  - Curated AI Guides & E-Books store with real-time search & filters.
  - Dynamic FAQ accordion and Newsletter briefing.
- **Dedicated Admin Control Suite (`/admin`)**:
  - Independent topbar with live system status, breadcrumbs, and user controls.
  - Sidebar for Guide management, Order tracking, User permissions, Coupons, and Points settings.
  - Completely decoupled from public header and footer.
- **Secure In-Browser Canvas DRM Reader**:
  - Anti-download & anti-scrape canvas rendering.
  - Dynamic cryptographic user watermarks.
  - Reading progress synchronization.
- **Built-in Demo Credentials**:
  - **Admin**: `admin@example.com` / `admin123`
  - **Student / User**: `student@example.com` / `student123`

## 🛠️ Tech Stack

- **Framework**: Next.js 15+ (App Router)
- **Frontend**: React (JSX), Tailwind CSS, Lucide Icons
- **Database**: MongoDB & Mongoose (with offline demo fallback)
- **Auth**: JWT Session Cookies (httpOnly, secure)

## 🏁 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Open http://localhost:3000
```
